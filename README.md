# 🚗 BeamNG.drive Mod Manager

Кросс-версионный портативный десктопный менеджер модификаций для **BeamNG.drive** на базе **.NET 8 (WPF)**. Поставляется в виде одного автономного `.exe` файла и не требует установки.

## 📥 Скачать готовую программу
Перейдите в раздел **[Releases](../../releases/latest)** справа и скачайте файл **`BeamNGModManager.exe`**.

## ✨ Основные возможности
- **Автоопределение путей (Path Resolver):** поддержка лицензий (Steam / Epic Games), портативных сборок (`startup.ini` с относительными путями `.\userfolder`), новых папок `%LocalAppData%\BeamNG\BeamNG.drive\current\mods`, реестра Windows и старых версий игры.
- **Менеджер профилей:** сохранение нескольких сборок и переключение между ними в один клик.
- **Умный установщик (Smart Installer):**
  - Установка через кнопку и перетаскиванием (**Drag-and-Drop**) прямо в окно программы.
  - Поддержка форматов `.zip`, `.rar` (включая RAR5) и `.7z`.
  - Автоматическая распаковка «матрёшек» и очистка рекламного мусора сайтов.
  - Защита от кривой упаковки: автоматическая сборка папок `vehicles/`, `levels/`, `lua/`, `art/` в правильный `.zip` архив.
- **Чтение метаданных без распаковки:** мгновенное отображение названия мода, автора, версии и превью-картинки из `info.json`.
- **Два режима отключения модов:** перенос в скрытую подпапку `_disabled` или использование жёстких ссылок NTFS (`Hardlinks`).
- **Инструменты обслуживания:**
  - Безопасная очистка кэша `temp` с **сохранением скомпилированных шейдеров (`shaders`)**.
  - Поиск файловых конфликтов между активными модами.
  - Быстрый запуск `BeamNG.drive.exe` прямо из менеджера.
- **12 языков интерфейса:** Русский, English, Deutsch, Español, Français, Português, Italiano, Polski, Türkçe, 中文, 日本語, 한국어.
