# Security Policy — BeamModManager Ultimate

## Supported Versions
Only the latest `2.8.x` release series receives security updates.

## Reporting a Vulnerability
If you discover a security issue (e.g., archive extraction bypass, Lua AST scanner evasion, or domain whitelist bypass), please open an issue in the repository using the Security / Bug Report template without publishing functional exploit payloads, or contact the maintainer (**Lancer10Evo**) via GitHub profile channels.
